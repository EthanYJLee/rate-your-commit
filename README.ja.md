## こんな悩みはありませんか?

小〜中規模の開発組織を運営していると、こんな瞬間に出会います。

- 「〇〇さんの成果が良いのは分かっているけど、いざ根拠を示せと言われると答えに詰まる」
- 「一人が複数のGitHub/GitLabアカウントを持っていて、誰が何をしたのか集計が合わない」
- 「評価シーズンのたびに勘でグレードを付けていて、後で異議が出ても答えられない」
- 「パフォーマンス管理SaaSを検討したが、自社のコード/人事データを外部サーバーに預けるのは気が引ける」

RateYourCommitは、この課題を**セルフホスト型のオープンソース**で解決するためのプロジェクトです。

## 主な機能

- **🔗 アイデンティティの自動マッチング** — 一人が複数のgitアカウント/メールアドレスでコミットしていても、候補を自動で見つけて一人に統合します。（ルールベースのマッチング、確定は必ず人がクリック）
- **📊 説明可能なスコアカード** — デリバリー・コード品質・コラボレーションの指標を、組織が決めた重みで計算します。計算式はすべて公開されており、Excelでも検算できます。
- **🧹 外れ値の自動除外** — 「ライブラリを丸ごとコミット」のようなケースを自動検知し、スコア計算から除外します。
- **🔌 コネクタ構造** — GitHub、GitLab、Jira、Linearなど、すでに使っているツールをそのまま接続できます。新しいツール連携もプラグインを1つ追加するだけです。
- **🔒 完全セルフホスト** — コードも評価データも、自社サーバーの外に出ることはありません。

## AIをどこで使い、どこで使わないか

このプロジェクトで最も重要な原則です。

> **報酬・グレードに直接影響する計算にはAIを一切使いません。** すべて人の手で検算できるルールと統計だけで構成されています。

AI（LLM）は最終スコアに影響しない**参考用の補助機能**として、2箇所のみに限定して任意で使用します（コミットメッセージの要約、ピア評価コメントの要約）。これらについても、社内ローカルLLMと外部APIを選択できるようにする予定です。詳細は[`docs/AI-POLICY.md`](docs/AI-POLICY.md)を参照してください。

## 5分で始める

```bash
git clone https://github.com/<your-username>/rate-your-commit
cd rate-your-commit
cp .env.example .env       # GitHubトークンなど最小限の設定
docker compose up -d       # web + worker + postgres を一括起動
```

ブラウザで`http://localhost:3000`にアクセス → リポジトリを接続 → 数分後に最初のダッシュボードを確認。専任のインフラ担当者がいなくても、社内の開発者一人で十分です。詳しいアーキテクチャは[`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)を参照してください。
